# Droplet 设计规范

> 版本 v2.1 · 2026-10-12 · 实现 小水滴
> 本文件是开发契约，不是提案。改代码之前先改这里。

**v2.1 变更**：首屏导语与 `Tracking…` 光标删除（首屏只留铭牌 / 水滴 / SCROLL）；站名降为铭牌尺寸；
星空改为恒定漂移 + 偶发流星，鼠标不再驱动任何背景；日志区固定三列，按组拼接素材；
文章页加入极昼模式（三体 8 字轨道，leapfrog 积分）；Inkstone MCP 客户端与 OAuth 授权链路就位。

---

## 1. 概念

**一句话**：你是人类舰队的一名观测员。透过驾驶舱的四扇观测窗，你看到吸积盘的全景——以及那颗正在被全舰队雷达锁定的三体探测器：水滴。

**题眼（三体）**：水滴是强互作用力材料做的，表面绝对光滑，绝对零度。全站的质感语言是**绝对光滑（水滴）vs 粗糙舱体（人类造物）**的对比，不做泛泛的科幻霓虹。

**隐喻**：真空里没有重力，水滴靠表面张力维持最完美的球形。写作同理——把想法压缩到最小体积，密度大到不会散。水滴 = 博主化身。

**不可协商的两条底线**

1. 文章正文可读性优先于一切视觉效果。
2. 任何动效不得干扰阅读；`prefers-reduced-motion` 时全站静止。

---

## 2. 设计原则

| 原则 | 含义 |
| --- | --- |
| 场景优先 | 每个区块都在"驾驶舱"里有位置：观测窗、舱体、HUD、档案、日志 |
| 黑暗森林 | 近纯黑底。光是稀缺的，红是危险的，都省着用 |
| 形制硬朗 | 方角、切角、1px 细线、等宽字体。**禁止**：圆角卡片、毛玻璃、渐变镀铬、药丸按钮、横向滚动词条带、顶部进度条 |
| 动效服务于深度 | 视差是为了"舱体比宇宙近"，不是为了炫 |
| 降级是及格线 | 减少动效、无 JS、窄屏三种情况下站都可用 |
| 素材即资产 | 不引入任何外部字体、图标库、图片 CDN |

## 3. 视觉体系

### 3.1 色板（黑暗森林）

```css
--void:       #000000;   /* 纯黑：黑到能藏住一支舰队 */
--bulk:       #06080a;   /* 舱体 */
--bulk-2:     #0a0d10;
--ink:        #dde3ea;   /* 正文 */
--ink-dim:    rgba(221,227,234,.58);
--ink-faint:  rgba(221,227,234,.30);
--line:       rgba(221,227,234,.13);
--line-strong:rgba(221,227,234,.30);
--signal:     #ff453a;   /* 警示红：只用于锁定/警示/关键节点 */
--cold:       #9fc2e8;   /* 冷钢蓝：HUD 辅助信息 */
```

规则：`--signal` 一屏最多 2 处；`--cold` 只做辅助，不做主色。正文永远接近纯白。

### 3.2 字体

- HUD / 标签 / 读数 / 区块标题：`--mono`（系统等宽栈），小号 + 大写字距
- 正文：`--sans`（PingFang / 雅黑），17px / 1.85
- 站名 DROPLET：mono 700，letter-spacing .16em

**不用衬线。** 衬线是上一版"老"的根源之一。

### 3.3 形制语汇

- 角标 `⌐ ¬`（1px 细框，只画两个相邻边）—— 用于视窗四角、相框
- 切角 `clip-path`（16px 斜切）—— 用于舷窗
- 括号 `[ ]` —— 用于按钮、眉题
- `//` 与 `01` 序号 —— 用于区块标题（`01 舱段档案 // About`）
- 扫描线（1px/3px，overlay 混合）—— 只用于首屏

## 4. 页面结构

### 4.1 首页（单页滚动）

```
Hero（100svh，驾驶舱）
  ├ 舱体 bulkhead：拉丝金属 + 接缝 + 边缘压暗
  ├ 视窗 viewport：B1–B4 四窗 + 三道金属隔柱（mullion）
  │   └ 每窗：切角窗框 + 景观 img(scale 1.18) + 玻璃反光层
  ├ 扫描线 + 中央暗角
  ├ HUD：左上观测读数（含递减的 DIST）/ 右下系统状态 + 任务时钟
  ├ 页面正中：水滴 + 雷达跟踪环 + PROBE-001 读数（与舷窗中心重合）
  ├ 顶端铭牌：眉题 + 小号 DROPLET（mono 大写，~19–31px，与跟踪环互不干扰）
  └ 底端：`SCROLL` + 1px 下滑线（滚动时随铭牌一起淡出）
01 舱段档案 About（文案 + Cover.jpg 相框，角标 + mono 图注）
02 在轨日志 Log（三列方角卡片网格，每页一张图，行内素材拼接）
页脚（[ 建立通讯 ] 方角按钮 + mono 版权）
```

**首屏只允许三件东西**：铭牌、水滴、SCROLL。任何新的说明性文字都要先说服这一条，否则不加。

### 4.2 文章页

```
← 返回观测窗
[ 极昼 ]（仅文章页出现）
标题 / 日期 // 标签（mono meta）
单张封面（可选，细线相框，完整显示，不裁切）
正文（prose，68ch / 17px / 1.85）
← 返回 / END OF FILE
右下角小水滴（72px 徽章，回首页）
```

文章页**不出现**：舷窗、扫描线、跟随大图。极昼模式只在文章页提供入口；开启后正文切换为浅色高对比，右侧显示三体系统。

## 5. 组件规格

### 5.1 舷窗 Viewport（v2 重做）

四层结构，深度来自**窗框不动、景象动得多**：

| 层 | 元素 | 行为 |
| --- | --- | --- |
| 舱体（最近） | `.bulkhead` | 拉丝纹理 + 水平接缝线 + 径向压暗 |
| 隔柱 | `.mullion` ×3 | 宽 `clamp(20px,3vw,52px)`，金属渐变 + 结构肋 + 上下螺栓 + 呼吸红灯 |
| 玻璃 | `.glass` | 反光随鼠标**同向**（映舱内），幅度 14px×depth |
| 景观（最远） | `.window img` | `scale(1.18)`，随鼠标**反向** 22px×depth + 自漂移（drift 0.05rad/s） |

- 四窗 depth 依次为 `1.0 / 0.78 / 0.56 / 0.38`（假弧形舱盖，靠边动得少）
- 窗框切角 `clip-path`，inset 1px 亮线
- 窄屏（≤760px）：隐藏四窗与隔柱，显示 B.jpg 全景单窗

**硬约束**：四窗画面必须横向连续——容器比例保持 < 素材比例 0.5，只纵向裁切。

### 5.2 水滴 Droplet（三体探测器）

**素材**：`Droplet.png` —— **人工抠图**（用户手工制作，禁止再用脚本生成）。
主体高占画面 45.7%，`createDroplet` 的 `size` 指**本体高度**，内部按 `fill=0.457` 换算。

**位置**：首屏页面正中，`.droplet-mount` 的零尺寸原点与视口内容区中心重合（`left: 50%; top: 50%`），
水滴视觉中心即该原点。眉题与站名作为铭牌留在上方安全区，`SCROLL` 沉到首屏底端，
中心的留白只服务水滴与跟踪环。

**物理**（`src/droplet.js`，全部 transform/opacity + rAF）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `reach` | 26px | 最大跟随位移（随距离渐入：dist/320） |
| 弹簧 | K=34, D=9.5 | 半隐式欧拉 |
| `tilt` | ≤10° | 随水平速度倾斜 |
| `squash` | ≤0.12 | 速度方向挤压拉伸（rotate-scale-rotate） |
| `trail` | 6 | 逐级滞后残影（lag 0.24→0.115） |
| `float` | 5px | 空闲 1.2s 后失重漂浮 |

**跟踪环**（`reticle: true`，仅首屏）：旋转虚线环（26s/圈）+ 上下刻度 + 红色 mono 读数 `PROBE-001 // MIRROR SURFACE`，与水滴同一 assembly，一起动。

镜面质感：不加投影，只给一圈冷光晕 `drop-shadow(0 0 18px rgba(159,194,232,.22))`。

### 5.3 HUD

- 左上：观测读数——`VP-01..04`、赤经赤纬、`OBJ 水滴 // PROBE-001`、**`DIST 4.2460 LY ▼` 每秒 -0.000004（它在逼近）**
- 右下：`SYS // NOMINAL`、PWR/O2、任务时钟 `T+HH:MM:SS`
- 底端：`SCROLL` 提示（已随导语一起从首屏中剥离，只剩这一处提示动作）

### 5.4 卡片 Card

桌面端三列排布，列间无 gutter。卡片保留方角、1px `--line`、顶部微亮渐变。观测序列卡片静态时不做任何位移或缩放：同一 `panel` 的三张素材占满一行，行内按 `order` 从左到右拼成一条连续画面，因此这一行整体移动，行内顺序永不被打乱。

**hover（全卡通用）**：整卡 `translateY(-6px) scale(1.035)` 抬起放大、`z-index:3` 压过邻卡、边框提亮并压一层 22×46 投影；封面 `scale(1.06)` 并从 grayscale(0.3) 提到灰度归零、亮度 0.82→0.95；左上角出现**红色锁定角**。拼接卡同样参与（悬停时从整幅图里浮起一格，移开即归位）。

### 5.5 通讯按钮 Commbtn

方角细框 + `[ ]` 括号 + mono 大写。hover：边框变 `--signal`，底 6% 红，括号变红。

### 5.6 动效清单

| 动效 | 位置 | 实现 |
| --- | --- | --- |
| 稀疏暗星 | 全站背景 | Canvas ≤170 颗，深度决定大小/亮度，6% 红矮星，闪烁；**恒定漂移**（5.5px/s × 深度）＋滚动纵深，**不跟鼠标** |
| 流星 | 全站背景 | 每 5–13s 随机一颗，最短 1.3s 生命期，带亮头短划线，头尾各淡一次，同屏最多 2 颗 |
| 舷窗视差 | 首屏 | 见 5.1 |
| 首屏滚动视差 | Hero | 内容上移 0.24× 淡出，视窗 scale 1→1.035 |
| 逐字入场 | 首屏标题 | opacity + translate，60ms/字 |
| 卡片悬停 | 在轨日志 | 0.38s 抬起 + `scale(1.035)`，封面 `scale(1.06)` 恢复彩度 |
| FadeIn | 全站 `.fade` | IO once，margin 50px，delay/x/y/duration 可配 |
| 错峰渐入 | 卡片 | 90ms 递增 |
| 水滴 | 首屏/文章页 | 见 5.2 |
| 红灯呼吸 | 隔柱 | 3.2s ease-in-out |
| HUD 时钟 | 首屏 | 1s 间隔 |

**已移除**：进度条、Marquee、镀铬标题、毛玻璃药丸、3D 星云（太亮，不黑暗森林）、插图 3D 倾斜（与 HUD 语言不符）、
首屏导语与 `Tracking…` 光标（信息与 HUD 重复）、星空鼠标视差（读字时晃眼）。

## 6. 文章内容契约

位置：`content/posts/*.md`

```yaml
---
title: 标题            # 必填
date: 2026-09-15       # 必填，ISO
panel: A               # 可选，拼接组名；同一组的三张卡排在同一行
order: 1               # 可选，组内拼接序号，越小越靠左
tags: [设计, 前端]      # 可选
cover: Cover.jpg       # 可选，images/ 下的文件名
coverAspect: 1         # 可选，封面宽高比；懒加载前预留版位
excerpt: 一句话摘要     # 可选，缺省自动截取 96 字
---
```

- slug = 文件名去日期前缀（可用 `slug:` 覆盖）
- 排序以「行」为单位：行与行之间按组内最新 date 倒序，行内按 order 升序；没有 `panel` 的卡片各自独立成行
- markdown-it（`html: true, linkify: true`）
- 每篇文章只显示一张 `cover`；需要拼接的素材拆成多个内容页，共用同一个 `panel`，按 `order` 拼接
- 丢一个 `.md` 进目录即发布，无需改代码

正文：17px / 1.85 / `rgba(226,232,240,.94)` / 68ch；`h2` 前缀红色 `//`；行内代码冷蓝；`li::marker` 红色。

## 7. 降级

| 场景 | 行为 |
| --- | --- |
| `prefers-reduced-motion` | 全站静止；星空只画一帧；水滴一帧静态 |
| 标签页隐藏 | 暂停 rAF |
| 窄屏 ≤760px | 四窗 → B.jpg 单窗；隐藏右下 HUD |
| 无 JS | 舷窗与文字照常，水滴不出现 |

## 8. 性能预算

- 首屏图片：B1–B4（约 2MB）→ 待压 WebP ≤ 800KB
- Droplet.png 173KB → 可再压
- 运行时依赖：仅 markdown-it（JS 113KB / gzip 58KB）
- 无外部字体、无外部请求
